# Dated live evidence

These JSON files record sanitized observations and exact executed-byte hashes
from past investigations. They are not executable test fixtures, production
mapping tables or guarantees of current upstream availability.

Start with [current verification](../../VERIFICATION.md) and the
[investigation index](../../docs/investigations/README.md). Executable tests remain
in `tests/`; synthetic inputs and literal bridge snapshots remain in
[fixtures](../fixtures/).

New raw runs belong in ignored `reports/`. Only reviewed, sanitized release
summaries belong here. Never retain credentials, personal metadata URLs, signed
streams, raw player bodies or subtitle dialogue. Do not edit recorded data simply
to make a new run look healthy.
